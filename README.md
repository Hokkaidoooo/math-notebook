## 在线阅读

手机开流量或连接 Wi-Fi，打开网址即可。题图随阅读加载，无需导入资料包。

## 安卓离线阅读

点击页面右上角“在线阅读”，在“离线阅读”中下载完整压缩包。

1. 将离线包下载到手机并解压。
2. 用 Chrome 打开“数学错题本_手机版.html”。
3. 选择包内的“题图资料包.zip”，完成后即可断网阅读。

每次重新打开离线阅读器，选择一次题图资料包即可。题图资料包无需解压。

收藏与掌握标记保存在当前浏览器；在线版与本地离线版分别保存。
