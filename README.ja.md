# 数学の復習ノート

[简体中文](README.md) · [English](README.en.md) · [Español](README.es.md) · **日本語**

[オンライン版を開く](https://hokkaidoooo.github.io/math-notebook/)

数学の問題を復習するための中国語のノートです。35 のテーマをたどったり、2,611 件の問題・ノートをキーワードで検索したりできます。解法、間違いやすい点、関連知識や公式を確認でき、元の問題画像は拡大して読めます。

## オンラインで読む

スマートフォンやパソコンのブラウザーで開きます。画像は Wi-Fi やモバイル通信で必要なときに読み込まれます。アカウントの作成、コマンドの実行、画像の取り込みは不要です。

## Android でオフラインで読む

1. オンライン版の右上にある **在线阅读** を押し、**离线阅读**（オフライン閲覧）を開きます。[Android オフライン版のリリース](https://github.com/Hokkaidoooo/math-notebook/releases/tag/offline-20261117)から `math-notebook-android-offline.zip` を取得することもできます。容量は約 480 MB です。
2. スマートフォンで外側の ZIP を展開し、`数学错题本_手机版.html` を Chrome で開きます。
3. 展開したフォルダー内の `题图资料包.zip` を選びます。この画像用 ZIP は展開しません。オフライン版を開き直すたびに同じ ZIP を選びます。

## プライバシーとライセンス

お気に入りと習得済みのマークは、現在のブラウザーに保存されます。オンライン版とオフライン版の記録は別々で、相互にも端末間でも同期しません。

公開元は Hokkaidoooo です。リポジトリ全体に適用されるライセンスは明記されていません。同梱の [KaTeX のライセンス](vendor/katex/LICENSE)は KaTeX に適用され、ノート本文や問題画像には適用されません。
